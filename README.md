# Quadern de Watts

Web app instal·lable (PWA) del pla d'hivern de l'Albert, connectada directament amb Strava.

- `plan.json`: les sessions del pla. Claude l'actualitza per afegir setmanes noves.
- El progrés (ticks, sessions mogudes, ajustos) es guarda al mòbil.
- Les claus de Strava es guarden només al mòbil, mai al repositori.
- Quan canviï l'app (no el pla), cal pujar la `VERSION` de `sw.js`.
